## 五、已确认的长期决策（后续直接执行，不再重新讨论）

- **发布策略 = 路线 A**：仅本地自用，不上 GitHub Release、不接 Tauri 官方更新器。
  更新方式：`npm run tauri build` 后把 `src-tauri/target/release/daily-todo.exe` 覆盖到本地固定目录。
  *注意二进制名取自 Cargo `[package] name`，是 `daily-todo.exe`，不是 productName 的 `DailyTodo`*
- **DDL 语义方向 B**：起止同日的 once 任务不算 DDL；判定单一真相源为 `src/lib/ddl.ts`，
  其他位置一律调用其函数，禁止就地重写判定条件
- **数据兼容性**：可选字段判空一律用 `!= null`（同时放过 `null` 与 `undefined`），
  加载时 normalize 补全缺失字段，新建对象显式带新字段
- **协作边界**：AI 不代跑编译 / 构建 / 运行，由本人在 IDE 验证（见 `AGENTS.md`）

详细背景与事故复盘见 `.workbuddy/memory/MEMORY.md`。
