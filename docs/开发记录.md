### 阶段 7 已交付（追加）

- **删除归档页**：`src/views/ArchiveView.tsx` 与仅其使用的 `PlaceholderView`（`.tsx` / `.module.css`）一并移除；侧栏「归档」入口改为「长期」长期任务预览页。用户明确不需要归档/恢复能力。
- **长期任务预览页** `src/views/LongTermView.tsx` + `src/components/LongTermTaskRow/`：汇总 `isLongDdlTask`（once 且 endDate ≠ startDate）任务，按 待完成 / 已逾期 / 已完成 三组可折叠卡片展示；复用 `TaskItem` 卡片视觉，支持勾选完成、编辑、归档。判定与排序辅助函数加在 `src/lib/ddl.ts` 单一真相源（`longTermBucket` / `sortByEndDateAsc` / `sortByCompletedAtDesc`）。
- **长期任务勾选二次确认** `src/views/LongTermView.tsx` + `src/components/ConfirmDialog/`：在长期任务页勾选「完成」会写入 `completedAt`（完成日 = 今天），使任务今天之后不再出现在任何清单（中止未来显示）。该动作不可逆且代价明显，故仅在「未完成 → 完成」方向拦截，弹 `ConfirmDialog` 说明后果；「完成 → 取消完成」直接执行不弹窗。`ConfirmDialog` 新增 `confirmVariant`（danger/primary）开关，删除沿用 danger 红，标记完成用 primary 墨绿，避免语义错位。版本号升至 **0.2.3**（package.json / tauri.conf.json / Cargo.toml）。

## 五、已确认的长期决策（后续直接执行，不再重新讨论）

- **发布策略 = 路线 A**：仅本地自用，不上 GitHub Release、不接 Tauri 官方更新器。
  更新方式：`npm run tauri build` 后把 `src-tauri/target/release/daily-todo.exe` 覆盖到本地固定目录。
  *注意二进制名取自 Cargo `[package] name`，是 `daily-todo.exe`，不是 productName 的 `DailyTodo`*
- **DDL 语义方向 B**：起止同日的 once 任务不算 DDL；判定单一真相源为 `src/lib/ddl.ts`，
  其他位置一律调用其函数，禁止就地重写判定条件
- **数据兼容性**：可选字段判空一律用 `!= null`（同时放过 `null` 与 `undefined`），
  加载时 normalize 补全缺失字段，新建对象显式带新字段
- **协作边界**：AI 不代跑编译 / 构建 / 运行，由本人在 IDE 验证（见 `AGENTS.md`）

详细背景与事故复盘见 `.workbuddy/memory/MEMORY.md`。
