> 本文件是从早期矢量方案稿（两份 SVG）中提炼出的设计约束，供后续做表情变体与桌宠动画时查阅。
> 矢量路线已废弃（转向 AI 出图 + 位图素材），但下面这些约束仍然有效。

## 一、造型四原则

| 原则 | 做法 | 理由 |
|---|---|---|
| 剪影优先 | 头身分离、四肢贴边、外轮廓一笔画完 | 桌宠显示尺寸只有 96–160px，内部细节在 64px 下会糊成一团，只有剪影能保命 |
| 古板靠「直线」 | 嘴是一条横线，眼是方点，永不微笑 | 嘴角只要上翘 1px，严肃人设就崩了；直线嘴是唯一可靠的「不笑」表达 |
| 呆感靠「比例」 | 头身比接近 1:1，四肢短、直、无关节 | 不需要做表情就能呆，动起来也只需要整体位移 |
| 萌点靠「一根天线」 | 头顶单根天线 + 末端小球 | 唯一的非功能部件，是全部灵气的来源，也是所有情绪动画的出口 |

## 二、人设关键词

呆 · 可爱 · 严肃 · 小古板 · 有萌点 · 线条简单 · 不花里胡哨

一句话画像：**一台一身软乎乎绘本质感、却系着领带规规矩矩上班的机器人。**

## 三、选型记录

早期四款造型方案（同一套墨绿工房色板、同一套线宽）：

| 方案 | 古板来源 | 萌点来源 | 工程代价 |
|---|---|---|---|
| Q-01 方块干事 | 直角方正、整块屏脸、胸口铭牌 | 头身比 1:1、天线、短腿 | 最低，全部矩形 |
| O-02 圆壳委员 | 竖点眼 + 一字嘴、站姿笔直 | 圆角壳、矮胖 | 低，脸屏独立好做表情 |
| C-03 显像管 | 老式显示器造型、旋钮耳 | 头重脚轻、折线天线 | 中，梯形是 path |
| P-04 轮式 | 帽檐压眉、站得笔直 | 没有腿，靠独轮挪 | 中，轮转单独处理 |

最终走位图路线，Q-01 的选型理由仍然成立：全矩形结构意味着动画时每个部件都是可预测的包围盒；剪影「大方块 + 一根天线」在小尺寸下最抗打。

## 四、表情设计约束（硬线）

只有有限几个状态，且变化只允许发生在三个地方：

1. **眼睛**——方点 ↔ 横线
2. **天线**——直立 ↔ 歪倒 ↔ 变红
3. **嘴**——**唯一一次破功**

嘴角上翘只在「完成任务」时出现，且只翘 2px。这个克制是刻意的：一台永远不苟言笑的机器，为了你完成一件事而翘了一下嘴角，这个反差才是萌点本身。如果它天天笑，萌点就没了。

## 五、画风与渲染档位

- 早期结论：粗描边卡通（外框 4px / 内部 2.5px）是矢量路线里唯一同时解决「图标感」和「壁纸分离度」的方案
- 但扁平始终是天花板：SVG 到「渐变 + 厚度 + 高光 + 落地投影」就是极限，画不出手绘笔触与厚涂堆叠
- **最终路线**：位图（AI 出图 + 抠图），厚涂绘本风，软体积、柔光感、脚下柔和阴影

## 六、配色（墨绿工房）

机身浅绿灰 `#e8eee5` · 深墨绿描边 `#2a332b` · 强调墨绿 `#2c7a53` · 备注灰 `#75806f`

三色封顶，不加渐变不加高光（位图路线下的明暗由绘本质感自然提供，不额外叠色）。

## 七、小尺寸约束（96–160px）

- 细节尺寸过小的部件（关节球、铭牌文字、过细天线）在 128px 下会退化成噪点——**新增部件前先过这一关**
- 屏脸五官占比要够大，否则表情在小尺寸下不可辨
- 竖长条形元素（领带、天线）在小尺寸下可读性好，可用

## 八、位图路线的已知代价

1. **主题切换**：PNG 颜色不随 CSS 变量走，深浅主题各需一套素材
2. **边缘白边**：抠图残余半透明像素在深色壁纸上显示为灰边（当前抠图脚本用「只降 alpha 不改 RGB」的羽化规避）
3. **表情一致性**：必须用「基于定稿图局部编辑」而非「每次重新生成」——AI 单次出图好看，但多张之间脸型/配色会漂移
